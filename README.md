# Reel Radar — упрощённый Virlo за $0

Каждый день собирает Reels англоязычных авторов ниши **AI-арт и AI-анимация**, считает, какие ролики «залетели», и показывает их на веб-дашборде.

```
GitHub Actions (cron)  →  Apify (скрапинг Reels)  →  Supabase (Postgres + расчёт)  →  дашборд на GitHub Pages
```

| Часть | Сервис | Бесплатный лимит |
|---|---|---|
| Сбор данных | Apify | $5 кредита в месяц; когда он кончается, запуски просто блокируются до следующего месяца — списаний нет |
| База и расчёты | Supabase | Free tier: 500 МБ — хватит на сотни тысяч роликов |
| Расписание | GitHub Actions | Публичный репозиторий — без лимита; приватный — 2000 мин/мес (нужно ~5 мин/день) |
| Дашборд | GitHub Pages | Бесплатно |

## Как это работает

**discover** (по понедельникам). Берёт топ-Reels по хэштегам ниши (`#aiart #aianimation #aivideo #aicartoon …`), сохраняет их и записывает авторов в кандидаты. Лучших кандидатов с англоязычными подписями переводит в отслеживаемые — пока не наберётся `MAX_CREATORS`.

**track** (каждый день). Для каждого отслеживаемого автора забирает последние `REELS_PER_CREATOR` роликов и пишет снимок просмотров. Авторов, у которых подписи явно не на английском, возвращает в кандидаты, чтобы освободить место.

**Расчёт** (view в Supabase, пересчитывается при каждом запросе):
- **outlier** = просмотры ÷ медиана просмотров последних 30 роликов автора (нужно ≥ 5 роликов в базе). ×3+ — «зашёл», ×10+ — «залетел»;
- **скорость** = прирост просмотров в час между двумя последними замерами;
- **ER** = (лайки + комментарии) ÷ просмотры;
- **тренды хэштегов** — какие теги чаще встречаются в роликах ×3+ на этой неделе против прошлой.

> «Американский сегмент» здесь определяется косвенно — по английскому языку подписей. Instagram не отдаёт географию аудитории чужих аккаунтов. Если нужна точность, добавляйте проверенных американских авторов в `seeds.txt` и блокируйте лишних (см. ниже).

## Установка (≈ 20 минут)

### 1. Supabase — уже готово
Проект **reel-radar** (регион us-east-1, free tier) создан, схема из `supabase/schema.sql` применена, `docs/config.js` заполнен.
Осталось одно: Supabase → проект reel-radar → Project Settings → API Keys → скопируйте **service_role** (или secret) ключ — он понадобится на шаге 3.
Project URL: `https://tqgprzuesxdhnrkeqkuz.supabase.co`

### 2. Apify
1. Зарегистрируйтесь на apify.com (карта не нужна).
2. Settings → Integrations → скопируйте **Personal API token**.

### 3. GitHub
1. Создайте репозиторий и загрузите в него эту папку целиком (включая `.github`).
2. Settings → Secrets and variables → Actions → **New repository secret**:
   - `APIFY_TOKEN`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_KEY` — именно service_role, он нужен для записи.
3. Actions → **Collect Reels** → Run workflow → выберите `discover`. Через 5–10 минут в базе появятся первые ролики и авторы. Затем запустите `track`.

### 4. Дашборд
1. `docs/config.js` уже содержит адрес проекта и публичный anon-ключ. Ключ service_role туда никогда не вписывайте.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs`.
3. Дашборд откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Без заполненного `config.js` дашборд показывает демо-данные — так можно посмотреть интерфейс заранее.

## Бюджет: как остаться в $5/месяц

Скраперы по умолчанию — `rowfinch/instagram-reel-scraper` и `rowfinch/instagram-hashtag-scraper`. На бесплатном плане Apify они отдают **не больше 100 результатов за запуск**, поэтому сбор автоматически разбивается на пачки по 100 (`MAX_ITEMS_PER_RUN`).

Фактическая стоимость по первым запускам: около $0,04–0,06 за пачку из 100 роликов.

| Что | Запусков | ≈ Стоимость в месяц |
|---|---|---|
| track: 40 авторов × 5 роликов, каждый день | 2 в день | $3,4 |
| discover: 8 хэштегов × 40 роликов, раз в неделю | 4 в неделю | $0,7 |
| **Итого** | | **≈ $4** |

Если кредита не хватает, уменьшите `MAX_CREATORS` или `REELS_PER_CREATOR`. Если кредит кончится, Apify заблокирует запуски до следующего месяца — платить не придётся.

**Догрузка истории.** Для outlier нужно хотя бы 5 роликов автора в базе. Чтобы не ждать неделю, после добавления новых авторов один раз запустите вручную `track` с параметром «Роликов на автора» = `15` (≈ $0,35 за 40 авторов).

## Настройки

GitHub → Settings → Secrets and variables → Actions → **Variables** (все необязательные):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `HASHTAGS` | `aiart,aianimation,aivideo,aiartwork,aicartoon,aishortfilm,aianimated,midjourneyart` | Хэштеги ниши для discover |
| `HASHTAG_RESULTS` | `40` | Топ-роликов на хэштег |
| `MAX_CREATORS` | `40` | Сколько авторов отслеживать |
| `REELS_PER_CREATOR` | `5` | Роликов автора за ежедневный прогон |
| `MAX_ITEMS_PER_RUN` | `100` | Размер пачки (лимит бесплатного плана Apify) |
| `MIN_ENGLISH_SCORE` | `0.6` | Порог англоязычности 0..1 |
| `MAX_CHARGE_PER_RUN_USD` | `0.25` | Потолок стоимости одного запуска |
| `REEL_ACTOR` / `HASHTAG_ACTOR` | rowfinch/… | Другой Apify-скрапер, если этот сломается (например, официальный `apify/instagram-reel-scraper`) |

**Свои авторы** — `seeds.txt`, по одному username на строку. Они отслеживаются всегда.

**Проверка языка.** Англоязычность автора оценивается по служебным словам в подписях: английские против хинглиша, узбекского, индонезийского, португальского, испанского, французского, турецкого и немецкого, написанных латиницей. Хэштеги не учитываются. Отслеживаемый автор, у которого балл ниже `MIN_ENGLISH_SCORE` (оценено ≥ 3 подписей), получает статус `rejected` и исчезает с дашборда; discover его больше не вернёт. Авторы из `seeds.txt` не отклоняются.

Перепроверить всех авторов по уже собранным подписям (бесплатно, без Apify): Actions → Collect Reels → Run workflow → `rescore`.

**Заблокировать или вернуть автора** — в Supabase SQL Editor:
```sql
update creators set status = 'blocked' where username = 'someone';    -- убрать навсегда
update creators set status = 'tracked' where username = 'someone';    -- вернуть
```

## Ограничения
- Скрапинг противоречит правилам Instagram. Скраперы иногда ломаются после изменений на стороне Instagram — тогда смените `REEL_ACTOR`.
- Превью из Instagram CDN со временем перестают открываться; карточка всё равно ведёт на сам Reel.
- Supabase Free ставит проект на паузу после 7 дней без активности, а GitHub отключает cron в репозитории, где 60 дней не было коммитов. Ежедневный сбор держит базу активной; раз в пару месяцев делайте любой коммит.
- Outlier появляется у автора, только когда в базе есть ≥ 5 его роликов — обычно после первого track.
